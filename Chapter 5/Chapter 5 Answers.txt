Exercise 5.7

What is the value of x after each of the following statements is executed?

a) x = Math.abs(7.5);
Answer: 7.5

b) x = Math.floor(7.5);
Answer: 7.0

c) x = Math.abs(0.0);
Answer: 0.0

d) x = Math.ceil(0.0);
Answer: 0.0

e) x = Math.abs(-6.4);
Answer: 6.4

f) x = Math.ceil(-6.4);
Answer: -6.0

g) x = Math.ceil(-Math.abs(-8 + Math.floor(-5.5)));
Answer: -14.0

Explanation for (g): First we work from the inside out. Math.floor(-5.5) is -6.0 because floor rounds down to the nearest whole number. So -8 + (-6.0) = -14.0. Then Math.abs(-14.0) = 14.0. Then the negative sign outside makes it -14.0. Then Math.ceil(-14.0) = -14.0 because ceil rounds up and -14.0 is already a whole number.
